## 2. 市场通用功能分类

### 2.1 拍照批改

识别整页题目和学生已经写下的答案，再判断对错并标注错误位置。必须处理题目切分、手写答案、涂改、题号对应和原图定位。

### 2.2 拍照搜题

识别题目后，从题库查找相同或相似题，返回已有答案、解析或视频。核心资产是合法题库、解析内容和检索质量。

### 2.3 AI解题与讲解

识别题目后自动求解并生成分步解释，不一定需要学生答案。可由求解器、教学模板、题库解析和大模型组合完成。

### 2.4 错题与学情闭环

将错题关联到知识点、错误类型和作答历史，支持订正、重练、打印和学习报告。错题本的存在本身不能证明使用了复杂知识追踪模型。

### 2.5 试卷数字化

去手写、还原空白试卷、整理错题和导出打印。这是图像处理与学习资料管理能力，不应和自动判题混为一项。

## 3. 三类核心能力的区别

- **拍照搜题**：识别题目 → 检索题库 → 返回已有解析。
- **AI解题**：识别题目 → 自动求解 → 生成讲解。
- **作业批改**：识别题目和学生答案 → 获得预期答案 → 比较与判题 → 错因辅导。

能解一道题不代表能可靠完成整页作业批改。

## 4. 可复用的体验设计

1. 拍照后允许调整取景框和编辑识别结果。
2. 原图、识别文本和判题结果保持对照。
3. 默认展示适合当前年级的解法，其他解法作为补充。
4. 分步展示“怎么做”和“为什么这样做”。
5. 识别失败不应消耗用户的答题权益。
6. 错题之后连接订正、同类练习和掌握状态。
7. AI和真人服务必须明确区分，包括费用、额度和等待时间。
8. 识别不清和暂不支持应成为可理解的正常产品状态。

## 5. 公开技术资料及证据边界

### 5.1 教育OCR和题目结构化

[阿里云教育场景OCR](https://help.aliyun.com/en/ocr/product-overview/education-scenario-recognition-1)公开提供：

- 印刷数学公式识别。
- 拍摄版和扫描版试卷切题。
- 题干、选项、答案等结构化结果。
- 跨栏、跨页题目关联。
- 限定范围的口算评测。

这些资料证明相关云能力存在，不证明它适用于本项目全部字迹和题型，也不代表已完成供应商选型。

### 5.2 手写数学和置信度

[Mathpix正式API文档](https://docs.mathpix.com/reference/post-v3-text)展示了：

- 数学、文本和表格图像处理。
- LaTeX、MathML等结构化输出。
- 印刷／手写属性。
- 行、词坐标与分层置信度。

置信度不是正确率保证，必须在本项目真实样本上确定使用阈值。面向儿童业务时，还需单独评估数据处理、服务区域和跨境问题。

### 5.3 拍照搜题检索

作业帮在[2020年公开技术分享](https://www.geekpark.net/news/271664)中曾披露“OCR＋检索”的历史架构，包括预处理、在线推理、正排、倒排和离线建库。

该资料只能证明当时公开的技术方向，不能当作其当前完整架构，也不能直接推断其他产品的实现。

### 5.4 数学判分

[STACK数学判分文档](https://docs.stack-assessment.org/en/Authoring/Answer_Tests/Equivalence/)展示了表达式树、交换／结合规则和计算机代数系统的代数等价判断，同时说明：

- 最终答案等价不等于过程正确。
- 数学等价不等于满足题目要求。
- 约分、保留小数、单位和定义域等需要独立规则。

它证明的是数学判分方法，不是“拍照OCR到自动批改”的完整产品方案。

## 6. 典型工程方案（工程推断，不归属具体厂商）

### 6.1 整页批改

纸张检测 → 图像矫正 → 版面分析 → 切题 → 印刷／手写识别 → 题干与答案关联 → 判题 → 原图标注。

### 6.2 拍照搜题

OCR文本／公式 → 清洗归一化 → 候选召回 → 相似度排序 → 返回答案和解析。

工程上可组合关键词索引、向量检索、公式结构相似度、年级和知识点过滤，但不能声称任何特定竞品采用相同组合。

### 6.3 AI辅导

题库解析、求解轨迹、教学模板、授权知识库检索和大模型可组合使用。计算结果应尽可能由确定性规则或符号求解器复核。

## 7. 对本项目的结论

1. 市场已经成熟，单纯“拍照给答案”不足以形成差异化。
2. 首版应对标小猿AI的作业闭环和Photomath的识别确认体验，而不是复制所有功能。
3. 真正的壁垒是合法数据、题库与解析、判题规则、教学质量和长期评测，不是单次模型调用。
4. 没有合法题库时，不应把拍照搜题作为首版核心。
5. 应使用同一批授权、脱敏的真实作业，对竞品和候选服务进行横向实测，再确定支持范围。
